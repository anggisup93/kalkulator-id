Indeks Prestasi (IP) adalah rata-rata bobot nilai yang ditimbang jumlah SKS tiap mata kuliah. IP satu semester disebut IP semester, sedangkan gabungan seluruh semester disebut IP Kumulatif atau IPK.

Konversi nilai huruf ke bobot

Sebagian besar kampus di Indonesia memakai skala 4:

Beberapa kampus tidak memakai nilai plus dan minus. Ikuti pedoman akademik program studi Anda.

Menghitung IP semester

IP = Σ(bobot × SKS) / Σ(SKS)

Contoh: A (3 SKS), A- (3 SKS), B+ (2 SKS), B (2 SKS), C (3 SKS). Total bobot = 4×3 + 3,7×3 + 3,3×2 + 3×2 + 2×3 = 41,7. Total SKS = 13. IP = 41,7 / 13 = 3,21.

Menggabungkan dengan IPK lama

IPK baru = (IPK lama × SKS lama + Σ(bobot × SKS baru)) / (SKS lama + SKS baru)

IPK lama 3,40 dengan 72 SKS, lalu semester ini menambah 13 SKS dengan total bobot 41,7: IPK baru = (3,40×72 + 41,7) / (72 + 13) = 286,5 / 85 = 3,37.

Pertanyaan umum

Mata kuliah mengulang dihitung bagaimana?

Kebijakan tiap kampus berbeda: ada yang memakai nilai terbaru menggantikan yang lama, ada yang mengambil nilai tertinggi, ada pula yang tetap menghitung keduanya. Ikuti aturan resmi kampus.

IPK berapa untuk lulus dengan pujian?

Sebagai gambaran umum: di atas 3,00 memuaskan, di atas 3,50 sangat memuaskan, mendekati 4,00 dengan pujian. Predikat resmi dan syaratnya, termasuk batas masa studi dan larangan nilai tertentu, ditetapkan masing-masing kampus.

Apakah nilai D membuat harus mengulang?

Tidak selalu. D umumnya lulus tetapi menekan IPK. Banyak prodi membatasi jumlah D dan mensyaratkan tidak ada nilai E untuk kelulusan. Gunakan kalkulator IPK untuk mencoba beberapa skenario nilai.
